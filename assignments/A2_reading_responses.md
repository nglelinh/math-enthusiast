| | |
|--|--|
| **Weight** | 15% |
| **Due** | End of day before seminar in **W2, W3, W4, W6, W8, W10** (or as announced) |
| **Length** | 300–500 words each |
| **Outcomes** | LO1–LO4 (varies by week) |
| **AI tier** | **D** — tools allowed **with disclosure** |

## Purpose

Spaced retrieval and precise restatement before high-stakes papers. Low stakes; high frequency.

## Spec (pass / revise)

A response **passes** if **all** of the following hold:

1. **Precise claim.** States a mathematical claim or definition from the reading in your own words without slogan-only language.
2. **Engagement.** Connects to a specific section of the flagship (not a generic summary that could fit any article).
3. **One genuine question.** A question that could drive seminar discussion (not “what is math?”).
4. **Length & honesty.** 300–500 words; AI disclosure if tools used.
5. **No major false statement** about the theorem/problem (minor notation slips OK).

**Revise:** fails one or more items → one revision allowed within **7 days** of feedback; if then meeting the spec, counts as pass.

**Scoring.** Best **5 of 6** passes count. Each pass = full credit for that slot; the 15% is essentially “five passes.” (Instructor may convert to points if preferred: 3% × 5.)

## Template (suggested)

```text
Reading: [title]
Claim restated: ...
Why it is subtle / what I almost got wrong: ...
Connection or mechanism: ...
Discussion question: ...
AI disclosure: none | tool=…; used for…; I changed…
```

## What not to do

- Paste chatbot output without disclosure or verification.
- Write only history/biography with no mathematics.
- Submit late (no late A2; drop is built into best-of-6).
