# Riemann Hypothesis video learning path (seminar)

## Stage 0 — Orientation (~20 min)

**Goal:** State RH in one sentence; distinguish strip vs line.  
**Video:** Quanta / Kontorovich.  
**Expected:** LO6 seed — numerical checks ≠ proof.

## Stage 1 — Culture and first pictures (~20 min)

**Goal:** Euler product intuition; zeros as “music of primes” metaphor carefully.  
**Video:** Numberphile / Frenkel.  
**Read:** Clay RH overview page.

## Stage 2 — Formal map (~60–90 min)

**Goal:** Trivial vs non-trivial zeros; PNT vs RH error terms.  
**Video:** Vaaler Millennium lecture (skim if long); Conrey MoMath.  
**Read:** Conrey Notices survey abstract + course essay §§2–5.

## Stage 3 — Frontier taste (~30 min)

**Goal:** Partial theorems (zeros on the line; zero-free regions) vs full RH.  
**Video:** Numberphile “23% beyond RH” as culture of partial progress.  
**Write:** 150 words: “Proved … ; still open …”

## Stage 4 — Seminar brief (A3)

**Goal:** LO1 map + one surrounding theory (explicit formulas *or* function-field analogue).  
**Rule:** never claim RH from tables of zeros.

## Minimum package (one weekend)

Quanta → Numberphile Frenkel → Clay page → course essay §§1–5 → draft A3 outline.
