# Kakeya Conjecture — video research pack

**Mode:** math-video-researcher B + C  
**Date:** 2026-08-04  
**Status (as of 2026):**  
- 2D dimension: **proved** (Davies 1971; Hausdorff dim 2).  
- 3D set conjecture: **proved** (Wang–Zahl 2025, arXiv:2502.17655).  
- Dimensions $$n\ge 4$$: **still open**.  
- Stronger maximal-function forms: largely **open** even in 3D.
