# Atiyah–Singer index theorem — Mode B analysis (course extract)

## Core statement (slogan)

For a suitable elliptic operator $$D$$ on a compact manifold,

\[
\mathrm{ind}(D) := \dim\ker D - \dim\mathrm{coker}\, D
= \text{topological index built from characteristic classes of } (M,\sigma(D)).
\]

## Definitions students must freeze

| Term | Working meaning |
|------|-----------------|
| Elliptic operator | Principal symbol invertible away from zero section (PDE “nondegenerate”) |
| Analytic index | $$\dim\ker - \dim\mathrm{coker}$$ (Fredholm) |
| Topological index | Characteristic-class / K-theoretic expression for the same integer |
| Symbol $$\sigma(D)$$ | Highest-order algebraic data of $$D$$ on the cotangent bundle |

## Status

- **Theorem:** proved (early 1960s) with extensive later reformulations; **not open**.
- **Abel recognition:** 2004 (second Abel Prize), joint Atiyah–Singer.
- **Living frontier:** equivariant/families/noncommutative refinements; physics dialogues (anomalies, Dirac operators)—extensions, not a missing classical proof.

## Confusions (for lesson tables)

1. Index ≠ mere number of solutions (subtract cokernel).  
2. Not the planar Poincaré index of a vector field.  
3. Not “proved in 2004.”  
4. Topology computes index, does not exhibit all solutions.  
5. Physics is bridge/muse, not historical sole inventor of the theorem.
