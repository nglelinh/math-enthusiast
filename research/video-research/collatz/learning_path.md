# Collatz video learning path (seminar)

## Stage 0 — Orientation (~30 min)

**Goal:** State $$T$$, try $$n=6,7,27$$, feel hailstone dynamics.  
**Videos:** Veritasium; Numberphile Eisenbud.  
**Expected:** LO6 seed — simple ≠ easy; computation ≠ proof.

## Stage 1 — Core problem (~45 min)

**Goal:** History, names, Lagarias “dangerous problem” culture.  
**Videos:** Chamberland Part 1.  
**Read:** Wikipedia intro + Lagarias overview abstract.  
**Expected:** List three research directions beyond brute force.

## Stage 2 — Modern partial results (~90–120 min)

**Goal:** Distinguish full Collatz from almost-all theorems.  
**Videos:** Tao Notorious Collatz + slides PDF; optional IAS talk.  
**Read:** Quanta article; Tao blog Theorem 2 slogan.  
**Expected:** Write 150 words: “Tao proved … ; he did **not** prove …”

## Stage 3 — Studio (A5)

**Goal:** Personal experimental lab.  
**Course:** Ch.7 Explore Iteration.  
**Rules:** freeze definitions; log failures; never claim a full proof from plots.

## Minimum package (one weekend)

Veritasium → Numberphile → Chamberland → Tao slides PDF (skim) → Ch.1 essay exercises 1–4 → draft A5 question.
