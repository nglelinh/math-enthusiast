# Mirror Symmetry — learning path

## Stage 0 — Orientation
Read parent [Duality as a principle](../../../contents/en/chapter06/_posts/21-01-01-06_12_Duality_Principle.md) § mirror + dictionary.
Watch Witten orientation talk if available.

## Stage 1 — Prerequisites
- Complex manifolds / Kähler at slogan level  
- Symplectic manifolds; Lagrangian submanifolds  
- Derived categories as “homological algebra of sheaves” slogan  

## Stage 2 — Core
- A-model vs B-model  
- Hodge diamond flip intuition  
- SYZ torus fibration picture  
- HMS statement  

## Stage 3 — Research culture
- Gross–Siebert program pointer  
- Local CY HMS via SYZ (Chan-type talks)  

## Expected understanding
Students can state HMS and SYZ slogans, name status (program vs theorem islands), and link to T-duality and geometric Langlands bridges—not compute Fukaya categories.
