## Six pillars

1. **Numbers** — precision; extend $$\mathbb{N}\to\mathbb{Z}\to\mathbb{Q}\to\mathbb{R}$$ ($$\sqrt{2}$$ shock) $$\to\mathbb{C}$$
2. **Algebra** — laws of operations; Kepler wine-barrel proto-calculus
3. **Geometry** — similarity; parallel postulate → spherical / hyperbolic → Riemannian → gravity
4. **Probability** — uncertainty; gambling roots; universality; rare events still hard
5. **Analysis** — error bars; infinity with care; doubling bets; infinite monkeys (almost sure ≠ waiting time)
6. **Dynamics** — emergence; stable vs unstable equilibria; 2-body vs 3-body; chaos modeled by probability
